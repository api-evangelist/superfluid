# Superfluid

> Superfluid is a money-streaming protocol for real-time, on-chain cashflows — continuous "payments by the second" to any wallet address across EVM networks. Built by Superfluid Labs, it powers salaries, subscriptions, rewards, airdrops, vesting, and incentive distributions as programmable token streams and distribution pools. The protocol has streamed over $1.6B to 1.27M recipients.

Superfluid's developer surface is a web3 stack: first-party TypeScript SDKs, on-chain smart contracts, an embeddable checkout Widget, and a public read-only GraphQL Subgraph API (served via The Graph). There is no authenticated REST API; reads come from the subgraph and writes are on-chain transactions.

## APIs

- [Superfluid Subgraph API (GraphQL)](https://docs.superfluid.org/docs/technical-reference/Subgraph): Public GraphQL endpoint for querying streams/flows, distribution pools, accounts, SuperTokens, token statistics, and events across supported networks. Base mainnet endpoint: https://subgraph-endpoints.superfluid.dev/base-mainnet/protocol-v1
